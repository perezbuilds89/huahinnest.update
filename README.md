# HuaHinNest

En svensk kontakt i Hua Hin. Statisk hemsida (HTML, CSS, JavaScript) som publiceras på Render.

## Struktur

```
index.html                     Startsidan
css/style.css                  All design (färger, typsnitt, layout)
js/main.js                     Mobilmeny, kontaktformulär, årtal
kunskapsbank/index.html        Kunskapsbankens översikt
kunskapsbank/<guide>/index.html  En sida per guide
images/                        Alla bilder
sitemap.xml, robots.txt        För Google
```

## Bilder

Lägg bilderna i `images/` med exakt dessa namn:

- hero-horse-beach.jpg
- cristian-portrait.jpg
- lake-restaurant.jpg
- palm-beach.jpg
- fruit-market.jpg
- condo.jpg
- villa-street.jpg
- nature-mountain.jpg

## Publicering på Render

Static Site, Build Command: tomt, Publish Directory: `.`
